ContentFactory
An AI-powered content production system designed to automate the complete content lifecycle.

Vision

Build an intelligent content factory that can discover trends, research topics, generate scripts, create voiceovers, produce visuals and render complete videos.

Core capabilities (planned)
- Trend intelligence using vidIQ.
- AI-powered research and script generation.
- Automated voice generation.
- Programmatic video production.
- Reusable Claude Code Skills and agents.
Status: Initial development

Current focus: Experimenting with Claude Code architecture, Skills, agents and MCP integrations.
